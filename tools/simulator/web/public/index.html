03 / PRODUCT RESEARCH & DEVELOPMENT
Software shaped by its hardware.
01
FreeInk SDK
A shared foundation for pocket e-paper devices: display drivers, physical input, storage and a simulator that follows the actual buses.
02
lila reader
A fork of CrossPoint Reader, exploring typography, reading rhythm and a quiet interface for EPUB and plain text.
03
Tinta
A dedicated Mexican Spanish tutor. Small daily sessions, useful phrases and stories, with an offline course and review schedule.
The demo runs compiled C++ firmware against virtual hardware. E-paper timing and grayscale are models; optical ghosting, radio behavior and electrical reliability still need real-device testing. Device control placement follows Xteink’s user guides.
